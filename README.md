# 🦋 13주차 중간 시연 프로젝트: Butterfly Effect

> **"애벌레가 고난을 이겨내고 무지개 빛 나비가 되는 퀴즈 프로그램"**
> p5.js 라이브러리를 활용하여 전체 플레이 프로세스와 화면 전환을 구현한 웹 퀴즈 게임입니다.

---

## 📌 프로젝트 소개
단순한 텍스트 기반 퀴즈에서 벗어나, 사용자가 문제를 직접 등록하고 플레이할 수 있는 게임형 학습 도구입니다. 
제한 시간 내에 정답을 맞히면 포식자(팩맨)를 멀리 쫓아내고 애벌레가 성장하지만, 오답이 누적되거나 시간이 초과되면 포식자가 점점 다가와 애벌레를 위협하는 시각적 피드백을 제공합니다.

## 👥 팀원 소개
* **제작자**: [본인 이름 입력] / [팀원 이름 입력]

## 🕹️ 시연 프로세스 가이드 (화면 전환 순서)
1. **첫 화면 (소개 화면)**: 게임 제목, 제작자 명, 간단한 사용법 UI 확인
2. **문제 입력 모드**: 단일 문제 입력 및 대량 문제(Textarea) 등록 프로세스 진행
3. **퀴즈 플레이 화면**: 실시간 타이머 작동 및 오답 시 팩맨 추격 애니메이션 시연
4. **엔딩 화면**: 정답률(80% 기준)에 따른 WIN/LOSE 분기 처리 및 **엔딩 크레딧(Ending Credit)** 노출

---

* **Library**: p5.js v1.4.0
* **UI/Graphics**: p5 2D Canvas Graphics API & HTML5 DOM Elements
